# Sources du dataset v2

Chaque chiffre « réel » du générateur (`generer_patients.py`, `verite_cachee.py`) porte un tag dans le code. Ce fichier donne, pour chaque tag, la référence, le chiffre et le lien. **Toutes les citations ont été retrouvées mot pour mot** dans la source téléchargée (résumé PubMed, texte intégral ou rapport officiel) par un script de vérification indépendant de la recherche.

| Tag | Signification |
|---|---|
| `[SOURCE: clé]` | chiffre officiel ou publié, vérifié |
| `[REEL: clé]` | appris sur de vraies données patient publiques |
| `[CALE]` | calculé automatiquement pour retrouver une cible sourcée (voir `calage.json`) |
| `[HYPOTHESE]` | choix de l'équipe, **à valider par Ahmed** (liste en bas) |
