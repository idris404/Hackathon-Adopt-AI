# Longitudinal synthetic dataset

This directory links the 980 imported kidney profiles to deterministic assay
histories generated by `profile-history-generator-v1`.

- `source-cases.jsonl` contains profiles plus source serum and assay facts;
- `restitutions.jsonl` contains integrated deterministic analysis outputs;
- `history-generation-report.json` records generation seed, hashes, and
  coverage quotas;
- `dataset-report.json` records validation, distributions, missing data, and
  discordances.

The eight scenarios cover negative, positive, and doubtful constant histories;
both observed one-transition sequences; fluctuating histories; missing latest
results; and same-serum discordance. Scenario labels live only in provenance
and must not be used as model inputs. The quotas are not clinical prevalence.

No ordinal relationship between negative, doubtful, and positive is assumed.
One-transition sequences are described as `evolving` and retain an
`indeterminate` trend until a clinical rule is validated.
