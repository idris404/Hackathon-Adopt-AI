# Raw synthetic data

`patients_synthetiques_v3.csv.gz` is the sole active raw dataset. It contains
51,000 deterministic synthetic rows and is read directly as gzip by
`profile_importer.py`.

Do not edit this file. Normalization, kidney-only filtering, scoring, and label
separation belong in the importer. Its uncompressed SHA-256 is recorded in
`../processed/patient-profiles/profile-import-report.json`.
